Integration code to add to {{ site.url }}

  1. Download webpush-sw.js and publish it at the root of the site: {{ site.url }}/webpush-sw.js (the service worker receives the notifications; at the root it works on every page).
  2. Add this code to the pages (e.g. in the footer of the theme): a visitor enables the notifications with the button, the script does the rest (permission, subscription, renewal). 
    <script src="{{ public_url }}/static/webpush-client.js" defer
        data-api="{{ public_url }}/api/v1" data-site="{{ site.code }}"
        data-service-worker="/webpush-sw.js"></script>
<button type="button" data-webpush-toggle hidden
        data-label-on="Disable notifications">Enable notifications</button>
    The button stays hidden where push is not supported (or blocked by the visitor). Without the button, call WebPush.subscribe() from your own code; WebPush.state() tells subscribed, unsubscribed, blocked or unsupported.
  3. Queue the messages from the console (Messages) or from the CMS with an API token: 
    curl -X POST {{ public_url }}/api/v1/sites/{{ site.code }}/messages \
  -H "Authorization: Bearer wp_..." -H "Content-Type: application/json" \
  -d '{"title": "Title", "url": "{{ site.url }}/article", "options": {"body": "Text", "image": "https://..."}}'
